# Portfolio – Rangga Mayridho Jaman

Portfolio profesional pribadi Rangga Mayridho Jaman, dibangun dengan HTML, CSS, dan JavaScript murni (tanpa framework).

## 🎨 Fitur
- Tema **hitam & orange** modern dan profesional
- Animasi scroll yang halus (Intersection Observer)
- Efek tilt pada kartu
- Typed text animation di hero section
- Scroll progress bar
- Floating particles di hero
- Fully **responsive** (mobile, tablet, desktop)
- Navbar sticky dengan blur effect
- Timeline pengalaman yang interaktif

## 📁 Struktur File
```
portfolio-rangga/
├── index.html      # Halaman utama
├── style.css       # Styling (tema hitam-orange)
├── script.js       # Interaktivitas & animasi
├── vercel.json     # Konfigurasi deploy Vercel
└── README.md       # Dokumentasi ini
```

## 🚀 Deploy ke Vercel

### Cara 1 – Vercel CLI
```bash
npm i -g vercel
cd portfolio-rangga
vercel
```

### Cara 2 – GitHub + Vercel Dashboard
1. Push folder ini ke GitHub repository
2. Buka [vercel.com](https://vercel.com) dan login
3. Klik **"Add New Project"** → Import GitHub repo
4. Vercel otomatis detect sebagai static site → klik **Deploy**

## 🔗 Customize Social Media
Buka `index.html`, cari bagian `<!-- CONTACT -->` dan ganti `href="#"` dengan link sosial media:
```html
<a href="https://github.com/username" ...>
<a href="https://instagram.com/username" ...>
<a href="https://linkedin.com/in/username" ...>
```
